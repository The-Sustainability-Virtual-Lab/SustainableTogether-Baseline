# SustainableTogether-Baseline

The baseline system of the SustainableTogether project. It describes the
system as it is today, before any sustainability transformation. Each
transformation scenario (for example Regeneration or Circularity) starts
from a tagged version of this baseline, so that the scenarios stay
comparable.

## Contents

| Folder | Content |
|---|---|
| [`product/HomePV-SYSMOD/`](product/HomePV-SYSMOD/) | The product: a grid-tied residential photovoltaic system with battery storage, modeled in SysML v2 with the SYSMOD method |

New to the model? Start with the
[walkthrough](product/HomePV-SYSMOD/WALKTHROUGH.md).

## Versions

Each released baseline version has a git tag (for example `v1.0.0`).
A scenario names the tag it uses. The changes for each version are in
[CHANGELOG.md](CHANGELOG.md).
