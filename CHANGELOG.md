## [1.0.0] - 2026-11-17

The first baseline release. Scenarios that start from this baseline name
the tag `v1.0.0`.

### Added
- `product/HomePV-SYSMOD/`: the HomePV product model, a grid-tied
  residential PV system with battery storage, modeled in SysML v2 with
  SYSMOD (SysML v2 textual model, Cameo project, walkthrough, element
  documentation).
- `product/HomePV-SYSMOD/Views/`: 16 diagrams as SVG (vector source) and
  as PNG at double resolution, with "Open full size" links in the README
  and the walkthrough.

### Known limitations
- Five requirements are not yet satisfied: safe and low-maintenance,
  electrical safety, permitting, commissioning, servicing.
- The diagrams carry the Cameo "Academic Version" watermark, and some
  labels overlap.
